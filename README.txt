Tunisia Mall — نظام الطلبات والـAdmin

تم تجهيز قاعدة Supabase للمشروع sxajasczcwurclchyluf وإنشاء جدول orders مع RLS.

الملفات:
- index.html: واجهة المتجر والطلب.
- admin.html: لوحة الطلبات.
- script.js / admin.js: النظام.
- products.js: المنتجات التجريبية التي يمكنك استبدالها بمنتجاتك.
- supabase-config.js: إعداد Supabase الجاهز.
- style.css / admin.css: التصميم.

مهم:
1) ارفع الملفات إلى مستودع الموقع.
2) أنشئ حساب Admin من Supabase Authentication > Users > Add user.
3) افتح /admin.html وسجل الدخول بالحساب.
4) الطلبات ستدخل إلى Supabase وتظهر في لوحة Admin، كما يفتح إشعار WhatsApp للرقم 96416123.
5) الدفع مضبوط على الدفع عند الاستلام.

قاعدة البيانات تم إنشاؤها بالفعل في مشروع Supabase المتصل.
